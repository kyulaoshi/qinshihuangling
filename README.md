# 秦始皇陵大逃脱 — 진시황릉을 탈출해라!
**ESCAPE FROM THE TOMB OF QIN SHI HUANG** · 중학교 2학년 중국어 복습용 3D 방탈출 게임

## 바로 실행하기
- `dist/index.html` 파일 하나가 게임 전체입니다. 크롬이나 엣지로 더블클릭해서 열면 바로 실행됩니다.
- 설치할 프로그램이 없고, 외부 라이브러리·이미지·서버도 쓰지 않습니다. (3D 엔진은 WebGL2로 직접 작성)
- 인터넷이 연결돼 있으면 Google Fonts(Noto Serif SC/KR)를 불러와 글꼴이 더 예뻐지고, 오프라인이어도 시스템 글꼴로 정상 작동합니다.

## GitHub Pages에 배포하기
**방법 A — 가장 간단 (빌드 없이)**
1. GitHub에서 새 저장소를 만듭니다.
2. `dist/index.html`(과 `dist/.nojekyll`)을 저장소 최상위에 업로드합니다.
3. Settings → Pages → Branch를 `main` / `(root)`로 지정하고 저장합니다.
4. 1~2분 뒤 `https://<아이디>.github.io/<저장소이름>/` 주소를 학생들에게 공유합니다.

**방법 B — 소스 전체 업로드 (자동 빌드)**
1. 이 폴더 전체를 저장소에 올립니다(`.github/workflows/deploy.yml` 포함).
2. Settings → Pages → Source를 **GitHub Actions**로 선택합니다.
3. `main` 브랜치에 push할 때마다 `node build.js`가 실행되어 자동 배포됩니다.

## 소스 구조
```
src/
  index.template.html  화면 구성(시작·인트로·HUD·미션·결과)
  styles.css           고대 중국 + 게임 UI 스타일
  util.js              수학, 시드 난수, 중국어 숫자/날짜 변환, localStorage
  audio.js             Web Audio 효과음 합성 + 중국어 음성(zh-CN)
  renderer.js          WebGL2 렌더러(조명 12개, 안개, 불꽃·먼지 입자, 절차적 석벽 질감)
  world.js             6구역 맵(2m 격자), 병마용·보물 등 절차적 3D 모델, 문, 충돌
  missions.js          5개 미션 문제 데이터(객관식·그림·순서 배열·입력형)
  player.js            탐험가 캐릭터, 이동·달리기·점프, 3인칭 카메라(벽 관통 방지)
  ui.js                HUD, 미니맵, 미션 패널, 설정, 학습 기록, 결과 화면
  game.js              상태 관리, 이벤트, 저장/불러오기, 메인 루프
build.js               src → dist/index.html 한 파일로 합치기 (Node.js만 있으면 됨)
```
빌드: `node build.js`

## 문제 수정 방법 (교사용)
문제는 `src/missions.js`에 있습니다. 각 문제는 다음 형식입니다.
```js
q({ zh: '你几岁？', py: 'Nǐ jǐ suì?', ko: '너는 몇 살이니?',
    options: [{ zh: '我十四岁。', py: 'Wǒ shísì suì.' }, ...], answer: 0,
    hint: '힌트 문장', after: { zh: '정답 문장', py: '병음', ko: '뜻' } })
```
수정 후 `node build.js`로 다시 빌드하면 됩니다.

## MISSION 2 — 사라진 황제의 옥새 (추리 미션)
- 병마용의 방에 들어서면 사건이 발생하고, 방 곳곳의 반짝이는 단서 6개(사건 기록 · 장군/궁수/전차병/보병의 행동 기록 · 무덤 규칙 비석)를 찾아 `E`로 조사합니다.
- 단서는 사건 수첩(`N` 키 또는 화면 왼쪽 버튼)에 자동 기록되고, 수첩의 **时间表** 탭에서 장소 카드를 끌어다 놓거나 눌러서 시간표를 직접 채웁니다.
- **推理结果** 탭에서 범인과 그 이유를 모두 골라야 하며, 둘 중 하나라도 틀리면 같은 메시지로 오답 처리되어(우연히 맞히기 방지) 다시 도전합니다. 힌트는 3단계입니다.
- 정답 연출: 범인의 눈이 붉게 빛남 → 범인이 물러남 → 바닥 비밀칸에서 옥새가 떠오름 → 옥새 획득 → 비밀 통로(다음 구역 문) 개방, 이후 사건 해설이 공개됩니다.
- 정답과 해설은 `src/missions.js`의 `TEACHER_CASE`에 인코딩되어 있어 화면에 드러나지 않습니다. 정답은 **TEACHER.md** 참고(이 파일은 배포 폴더 `dist`에 포함되지 않습니다. 다만 저장소를 공개하면 학생도 볼 수 있으니 방법 A로 `dist`만 올리는 것을 권장합니다).

- 생명력 ❤️×3. 함정에 당하면 1개 감소, 모두 잃으면 현재 구역의 체크포인트에서 다시 시작(−50점, 생명 회복).
- 중국어 비석 8개: 보통·어려움 모드에서는 한국어 뜻이 가려져 있고, 힌트 1회를 써야 볼 수 있습니다(쉬움은 바로 표시).
- 아이템·생명력·체크포인트·읽은 단서는 모두 자동 저장되어 새로고침 후에도 이어집니다.

## 게임 규칙 요약
- 난이도: 쉬움(20분·힌트 무제한·선택지 4개) / 보통(15분·힌트 5회·선택지 3~4개) / 어려움(10분·힌트 2회·일부 직접 입력)
- 점수: 정답 +100, 첫 시도 +50, 힌트 −20, 미션 완료 +200, 전체 완료 보너스 +500
- 암호 숫자와 일부 문제(날씨·음식·가족 그림 등)는 게임마다 무작위로 바뀌어 옆 친구의 답을 그대로 베낄 수 없습니다.
- 진행 상황은 각 학생 브라우저의 localStorage에만 저장됩니다(외부 전송 없음). 새로고침해도 이어서 할 수 있습니다.
